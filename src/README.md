# Control Software

This directory contains the control software developed by **Volt** for the WRO 2026 Future Engineers competition.

The code documents the evolution of our autonomous vehicle, from the first hardware tests to the final competition programs. It includes prototypes used to test individual components, such as the motors, servo, ultrasonic sensors, and color sensor, as well as the complete autonomous driving algorithms.

The main functions implemented in the final software include:

- Autonomous vehicle movement and steering
- Ultrasonic wall and obstacle detection
- Continuous wall-centering corrections
- Automatic corner detection and turning
- TCS3200 color sensor integration
- Lap and line counting
- Obstacle avoidance
- Automatic stopping after completing the required laps

The different files in this directory are preserved to show the development and testing process that led to the final version uploaded to the robot.

## Software de Control

Este directorio contiene el software de control desarrollado por **Volt** para la competencia WRO 2026 Future Engineers.

Los códigos documentan la evolución de nuestro vehículo autónomo, desde las primeras pruebas de hardware hasta los programas finales utilizados en competencia. Se incluyen prototipos creados para probar individualmente componentes como los motores, el servomotor, los sensores ultrasónicos y el sensor de color, además de los algoritmos completos de conducción autónoma.

Las principales funciones implementadas en el software final incluyen:

- Movimiento y dirección autónoma del vehículo
- Detección de paredes y obstáculos mediante sensores ultrasónicos
- Correcciones continuas para mantener el vehículo centrado
- Detección automática de esquinas y ejecución de giros
- Integración del sensor de color TCS3200
- Conteo de líneas y vueltas
- Evasión de obstáculos
- Detención automática al completar las vueltas requeridas

Los diferentes archivos de este directorio se conservan para mostrar el proceso de desarrollo, prueba e iteración que llevó al código final cargado en el robot.
